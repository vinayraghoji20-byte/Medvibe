💊 MedVibe – Medicine Knowledge System

Smart Healthcare & Medicine Information Platform

📌 About the Project

MedVibe is a web-based Medicine Knowledge System designed to help users explore medicine information, understand medicine uses and possible side effects, and access basic healthcare appointment services.

The platform provides a simple and user-friendly interface for medicine searches, appointment requests, and expert consultation requests.

✨ Features

💊 Medicine Information

- Search for medicines by name.
- View generic medicine names.
- Explore primary uses and benefits.
- View dosage information.
- Read about possible side effects and warnings.
- Save favorite medicines.

🔍 Smart Medicine Search

- Medicine search functionality.
- Instant search suggestions.
- Filter the medicine list.
- View saved medicines separately.

📅 Appointment Booking

- Book healthcare appointments.
- Enter patient details.
- Select medical departments.
- Choose appointment dates and time slots.
- Track appointment status.

👨‍⚕️ Expert Consultation

- Submit expert callback requests.
- Describe symptoms or questions.
- Select request urgency.
- Track consultation request status.

🔐 Manager Dashboard

- Manager sign-in.
- View appointment requests.
- Manage expert consultation requests.
- Update request statuses.
- Add manager notes.
- View activity statistics.
- Export data in JSON and CSV formats.

🛠️ Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Interactive functionality.
- LocalStorage – Browser-based data storage.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Locate the HTML file.
4. Open the HTML file in a web browser.
5. Start exploring MedVibe!

🎯 Project Objective

The main objective of MedVibe is to create an accessible digital platform that organizes medicine information and provides basic healthcare appointment management features through a user-friendly website.

⚠️ Disclaimer

MedVibe is an informational and educational project. Medicine information is not a substitute for professional medical advice, diagnosis, or treatment.

Always consult a qualified healthcare professional before using medicines or changing a prescribed treatment.
